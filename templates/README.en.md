# Templates

Tiếng Việt: [README.md](README.md)

Each subdirectory is one design, usable for both **static HTML** and **WordPress** sites.

## Where templates live

| Directory | Used for |
|---|---|
| `templates/` in this repo | Lares's built-in templates. **Replaced** on every update (`install.sh` runs `git reset --hard`). Add templates here if you want to contribute them to the repo |
| `/var/lib/lares/templates/` on the VPS | **Your own templates**: kept when Lares is updated. A template here with the same `id` as a built-in one replaces the built-in one |
| `apps/server/data/templates/` | Your own templates when running in dev on your machine |

The custom template path can be changed with the `LARES_CUSTOM_TEMPLATES_DIR` variable. After adding or editing a template, just reopen the **Add site** form; there is no need to restart Lares.

## Template structure

```
nha-hang/                    ← id: lowercase letters, digits, hyphens
├── template.json            ← metadata + WordPress sample content
├── style.css                ← the template's own CSS (color variables + its blocks)
├── index.html               ← static HTML page
└── wordpress/
    └── home.html            ← WordPress home page (block markup)
```

Quickest way: copy `bat-dong-san/` or `doanh-nghiep/` to a new directory, change the `id` in `template.json`, then edit the content.

### `template.json`

```jsonc
{
  "id": "nha-hang",                       // same as the directory name
  "name": "Nhà hàng",                     // shown in the panel
  "description": "Thực đơn, đặt bàn, ...",
  "types": ["wordpress", "static"],       // drop "wordpress" for an HTML-only template
  "colors": { "primary": "#7a1f1f", "accent": "#e8b04b" },
  "previewImage": "https://...jpg",       // thumbnail in the panel
  "font": "https://fonts.googleapis.com/css2?family=Be+Vietnam+Pro:wght@400;600;800&display=swap",
  "defaults": {                           // used when the person creating the site leaves a field empty
    "siteName": "...", "tagline": "...", "phone": "...", "email": "...", "address": "..."
  },
  "wordpress": {
    "nav": [{ "label": "Thực đơn", "url": "/category/thuc-don/" }],
    "categories": [{ "slug": "thuc-don", "name": "Thực đơn" }],
    "posts": [{ "title": "...", "category": "thuc-don", "tags": ["Món chính"], "image": "https://...", "excerpt": "...", "content": "Đoạn 1\n\nĐoạn 2 có **chữ đậm**" }],
    "pages": [{ "title": "Liên hệ", "slug": "lien-he", "content": "**Hotline:** {{PHONE}}" }]
  }
}
```

(The sample values are a Vietnamese restaurant template: "Nhà hàng" = Restaurant, "Thực đơn" = Menu, "Liên hệ" = Contact.)

The `content` of posts/pages is plain text: a blank line separates paragraphs, and `**...**` is bold.

### Placeholders

Usable in `index.html`, `wordpress/home.html` and the content in `template.json`. Values are HTML-escaped automatically.

| Placeholder | Value |
|---|---|
| `{{SITE_NAME}}` | Brand name |
| `{{TAGLINE}}` | Slogan / short description |
| `{{PHONE}}`, `{{PHONE_LINK}}` | Phone number as displayed / digits only (for `tel:`) |
| `{{EMAIL}}`, `{{ADDRESS}}`, `{{YEAR}}` | Email, address, current year |
| `{{CSS}}` | (`index.html` only) all the CSS: `_base.css` + `style.css` |
| `{{CAT:slug}}` | (`home.html` only) ID of the WordPress category, for use in a Query Loop block |

### CSS

- `_base.css` (shared): container, `.btn-*` buttons, header `.site-header/.nav/.logo/.menu`, `.section`, `.section-head`, `.card`, `.quotes`, contact form `.contact-grid/.form`, footer `.site-footer/.footer-grid`.
- A template's `style.css` must define these variables: `--primary --primary-dark --accent --accent-dark --on-accent --text --heading --muted --bg --bg-alt --border --footer-bg --radius --shadow --shadow-lg`.
- `_wp.css` maps WordPress blocks onto the design (`wp-block-button.btn-accent` buttons, the `.post-grid` post grid, `.stats/.quotes` columns...).

### WordPress home page (`wordpress/home.html`)

Written in block markup (`<!-- wp:group -->...`). The header, footer, and post/category pages are generated by Lares from `nav` and the contact details. Tips:

- Build the page in the WordPress editor, then open the **Code editor** (Ctrl+Shift+Alt+M), copy it into `home.html` and replace the text with `{{SITE_NAME}}`...
- Posts by category: a `wp:query` block with `"taxQuery":{"category":[{{CAT:slug}}]}` and `"className":"post-grid"`.
- Complex decorative parts can use a `wp:html` block.

Check before use (in the repo): `npm test` checks the block structure of every built-in `home.html`; for your own templates, preview them in the panel (the **Preview** button).
