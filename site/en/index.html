Features

Day-to-day site work, without typing commands

Long jobs run as tasks with a live log. Creating a site, restoring, updating and migrating all undo themselves if something fails.

Sites in a few clicks

WordPress downloaded with its database and admin account. Next.js cloned from Git and run by systemd behind Nginx. PHP and static sites. No domain yet? Serve it on a port for now.

Automatic SSL

Let's Encrypt including aliases such as www, auto-renewal, forced HTTPS and HSTS. Warnings when DNS does not point here yet or a certificate is about to expire.

Backups and restore

Scheduled daily backups of files and databases, keeping several copies. A restore takes a safety copy first and rolls back on error.

Safe WordPress updates

Core, plugins, themes: Lares backs up, updates, checks the site again and restores it automatically if it broke.

Contact leads

Forms on every site land in one inbox, with instant Telegram or webhook alerts and CSV export.

Site builder

Pick an industry, enter the business details, choose colours and layout, and get a WordPress or static site. Five ready templates: spa, restaurant, real estate, company, product landing page.

Traffic logs

Requests, IPs, bandwidth, 2xx to 5xx status codes, top URLs and IPs by hour or day for each site, rotated logs included.

Cloudflare

DNS records created for new sites, the proxy toggled from the panel, and real visitor IPs kept when a site sits behind Cloudflare.

Everyday tools

One-click WP Admin login, Adminer, PHP upload and memory limits, site cloning for staging, an AI writer for SEO-ready posts.

Update WordPress without fearing a broken site

A plugin that breaks after an update is every WordPress maintainer's worry. Lares runs each update through the same fixed routine.

  • Records how the site looks before the update
  • Backs up files and the database
  • Updates core, plugins and themes, then checks the site again
  • Restores the backup automatically if the site broke
  • Keeps every run in the update history

A client website in minutes

Answer a few questions and Lares builds a complete website. You keep editing it as usual in WordPress or the HTML files.

  • Industry, brand colour, style and content blocks
  • Live preview before the site is created
  • WordPress output is a block theme you edit in wp-admin
  • Contact forms post straight to the Leads inbox
  • Save designs as your own templates, export and import as JSON

Never miss a lead from a contact form

Every site Lares manages accepts contact forms without a plugin. When a visitor leaves their details, you know right away.

  • One inbox for all sites: filters, notes, statuses
  • Telegram or webhook alerts
  • Spam protection with a honeypot field and rate limits
  • Old entries deleted after the retention period you set

Install

Install, upgrade and remove without touching what already runs

Install on a server in use

Existing nginx, MariaDB/MySQL and PHP-FPM are reused, never replaced. If another web server holds ports 80/443, Lares waits until you are ready to switch.

Upgrade with the same command

Only the panel pauses for a few seconds; websites keep running. The panel's settings and data are backed up before each upgrade.

Uninstall and keep your sites

By default only the panel is removed and sites keep running. Add --purge to remove everything; backups are always kept.

Security

It runs as root, so security comes first

Lares runs on your real servers, so everything is verifiable: the code is open and the data it sends is listed below.

  • Layered login protection

    Two-factor authentication (TOTP and recovery codes), IP allowlist, lockout after repeated failures, sign out everywhere.

  • Site code never runs as root

    wp-cli, npm and application commands run as the web user.

  • Secrets are encrypted

    API keys and database passwords are encrypted with AES-256-GCM and never sent back to the browser.

  • Adminer locked behind the panel

    Only reachable through a signed-in panel with one-time tickets. No database admin page exposed to the internet.

  • Open source, AGPL-3.0

    Anyone can read what Lares does on their server: github.com/tampham92/lares.

What Lares sends, in full

To know how many servers run Lares, the installer sends an anonymous counter on install and upgrade, and the panel once a day. It contains only:

  • a random install id
  • the Lares version and event (install, upgrade, daily)
  • OS name and version, CPU architecture
  • the panel language

No IPs, domains or site data, ever.

Turn it off with --no-telemetry at install time, or LARES_TELEMETRY=0 in /etc/lares/lares.env.

FAQ

Frequently asked questions

Is Lares free?

Yes. Lares is free software under the GNU AGPL-3.0: you may use, modify and redistribute it. If you modify Lares and let others use it over a network (for example as a hosting service), you must give them the source of your modified version.

What server do I need?

Ubuntu 22.04 / 24.04 or Debian 12, 64-bit (x86_64 or arm64), root access over SSH. At least 1 GB of RAM, 2 GB recommended (add swap on a 1 GB machine, the build needs memory). About 3 GB of disk for Lares and its packages. Open ports 22, 80, 443 and 8686 (the panel port, configurable).

Can I install it on a server that already hosts sites or another panel?

Yes. Lares reuses the existing nginx, MySQL/MariaDB and PHP-FPM instead of replacing them. If another web server holds ports 80/443, Lares's nginx waits (coexist mode) until you switch over. Then use Migration to bring the sites into Lares.

Do upgrades interrupt my websites?

No. Run the install command again: only the panel pauses for a few seconds while websites keep running. When a new version is out, the panel shows it along with the upgrade command.

Do I lose my sites if I uninstall Lares?

Not by default: the uninstaller removes only the panel and your sites keep running. Only --purge deletes what Lares created, backups excepted.

curl -sSL https://lares.thocode.dev/uninstall | sudo bash

What does Lares send to ThoCode?

Only an anonymous counter: a random install id, the Lares version, the event, OS name and version, CPU architecture and panel language. No IPs, domains or site data. Turn it off with --no-telemetry or LARES_TELEMETRY=0.

How is Lares different from aaPanel, CyberPanel or HestiaCP?

Lares focuses on WordPress and Next.js sites on a VPS and puts safe operations first: back up before changing anything, roll back on failure. It is written in TypeScript and fully open source, in English and Vietnamese. If you use one of those panels today, Lares can migrate your sites.

Forgot the password or lost the 2FA phone?

Over SSH: sudo lares reset-password, sudo lares disable-2fa, or sudo lares allowlist clear if the IP allowlist locked you out.
